# Separate shared encoding, backend code and RM legacy

- Timestamp: 2026-10-28 22:17 UTC
- Work item: REF-004
- Status: started

Audit encoding dependencies, extract Go-only transform execution into liftrs-go,
keep C++ kernels/binding in liftrs-cpp, and move common preprocessing, arithmetic,
encoding orchestration and oracle into liftrs-shared. Shared code remains Go code
used by both complete execution paths; C++ currently accelerates transforms.
Move RM-only Julia/C++ helpers, build files, plot and binaries into rme_legacy,
including the external-process implementation, retaining a thin explicit PIR
compatibility bridge. Preserve existing protocol behavior and historical measured
source manifests/results. Update active imports, build paths, documentation,
experiment source resolution and README; run default/tagged tests and native
checks without repeating expensive benchmarks. Earlier uncommitted native work
will be preserved and tracked rather than overwritten.
